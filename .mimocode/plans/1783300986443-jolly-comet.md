# 气溶胶展示优化：统一为「通透度」语义

## 背景

鲜艳度越高越好，气溶胶越低越好（越低空气越通透）。今日卡片已将气溶胶反转为「通透度」展示（进度条越满越好）。其余 5 处图表仍直接展示 AOD 原始值，导致视觉上「越大越好」的误导。

## 改动方案

统一将所有图表中的气溶胶改为「通透度」（`1 - aod`），视觉语言一致：**越高/越满 = 越好**。

### 1. aodChart 折线图（`renderCharts` ~L968）
- 数据从 `aod` 改为 `1 - aod`（通透度）
- Y 轴标签改为「通透度」
- 数据集中 label 从「气溶胶」改为「通透度」

### 2. bestDatesChart 最佳日期排行（`renderBestDates` ~L830）
- aodData 从 `d.aod` 改为 `d.aod != null ? 1 - d.aod : 0`
- dataset label 从「气溶胶」改为「通透度」

### 3. seasonChart 季节对比（`renderSeasonChart` ~L862）
- avg_aod 数据从 `s.avg_aod` 改为 `s.avg_aod != null ? 1 - s.avg_aod : 0`
- dataset label 从「平均气溶胶」改为「平均通透度」

### 4. modelCompareChart 模型对比（`renderModelCompare` ~L996）
- avg_aod 数据从 `found.avg_aod` 改为 `found.avg_aod != null ? 1 - found.avg_aod : 0`
- dataset label 从「气溶胶」改为「通透度」

### 5. monthlyChart 月度趋势（`renderMonthly` ~L1040）
- avg_aod 数据从 `m.avg_aod` 改为 `m.avg_aod != null ? 1 - m.avg_aod : 0`
- 右 Y 轴标题从「气溶胶」改为「通透度」

### 涉及文件
- `templates/index.html`（仅此一个文件）

### 不改动
- `aodLabel` 函数：保留，今日卡片的通透度标签仍可引用其逻辑（或保持 clarityLabel）
- 原始 aod 数据仍存入数据库，只是展示层反转
