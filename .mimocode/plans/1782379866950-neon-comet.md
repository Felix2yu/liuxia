# 流霞 (liuxia) 功能扩展计划

## 现有功能

| 类别 | 功能 |
|------|------|
| 获取 | 从 sunsetbot.top API 获取朝霞/晚霞预报（GFS/EC 模型） |
| 存储 | SQLite 持久化，upsert 自动更新 |
| 定时 | cron 按配置时间自动执行 |
| 通知 | ntfy 推送，优先级分级（1-5），质量<0.2过滤 |
| 展示 | Web 看板：筛选、折线图、表格、CSV/JSON 导出 |

## 可扩展功能（按用户偏好排序）

### 1. 数据分析与统计
- `/api/statistics` 端点：月度/年度平均鲜艳度、气溶胶
- 最佳观赏日期/季节排行
- GFS vs EC 模型预测差异对比
- 异常值标记与历史趋势分析

### 2. 增强通知
- 多渠道：Telegram Bot、邮件（SMTP）、微信（企业微信 API）
- 智能阈值：用户自定义 quality/aod 阈值过滤
- 每日/每周摘要推送
- 天气联动：结合实际云量、风速数据

### 3. API 与集成
- 分页 + 过滤 + 排序的完整 REST API
- Webhook 回调（数据更新时通知第三方）
- API Key 认证

### 4. 运维监控
- `/api/health` 健康检查端点
- 结构化日志（JSON 格式）
- 数据获取成功率统计
- 自动重试机制

### 5. 其他高优先级
- 多城市支持（配置文件/环境变量扩展）
- 移动端响应式适配
- 深色模式

## 关键文件

| 文件 | 职责 |
|------|------|
| `main.go` | 入口，cron 调度 |
| `predictor.go` | 数据获取、解析、通知 |
| `web.go` | Web 服务、API 端点 |
| `store.go` | SQLite 存储、查询、导出 |
| `config.go` | 环境变量配置 |
| `templates/index.html` | Web 看板页面 |

## 实施顺序

1. 历史统计功能（后端统计 API + 前端图表）
2. 多城市支持（配置 + 数据库 + 前端筛选）
3. 健康检查端点
4. 移动端适配
5. 其他按需扩展
