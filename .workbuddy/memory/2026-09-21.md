## 新增图表页面超长修复（chart-canvas 固定高度）

用户反馈散点及以下图表高达几十页。根因：5 个新单图（scatter/dist/eventTime/coverage/weekday）用了 `maintainAspectRatio: false`，但 `<canvas>` 直接放在无固定高度的 `.chart-body` 里 → Chart.js 经典无限增高 bug（父元素高度由 canvas 自身撑出，resize 循环放大）。分面图没事是因为 `.facet-canvas` 固定 216px；summary/cityCompare 没事是因为它们**没有**设 maintainAspectRatio:false（默认 true 按 aspectRatio 算）。

修复：新增 `.chart-canvas { position:relative; width:100%; height:340px }` 容器包裹 5 个 canvas（移动端媒体查询降到 260px），`maintainAspectRatio:false` 读父元素固定高度后即稳定。验证手法（可复用）：本机 workspace node_modules 里有 **playwright + chromium_headless_shell-1243**，可 `chromium.launch({ executablePath: ~/Library/Caches/ms-playwright/chromium_headless_shell-1243/.../chrome-headless-shell })` 真实加载页面并 `evaluate` 量 `getBoundingClientRect` / `body.scrollHeight`，比截图裁剪精确得多。修后 doc=8336px（1280 宽）/ 11519px（390 宽），5 个 canvas 全部 340/260。
